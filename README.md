# Quotex Signal Trading Bot

অ্যান্ড্রয়েডের জন্য একটি উন্নত ট্রেডিং সিগন্যাল অ্যাপ্লিকেশন যা ১০০টি প্রযুক্তিগত বিশ্লেষণ লজিক ব্যবহার করে রিয়েল মার্কেট ডেটা বিশ্লেষণ করে।

## বৈশিষ্ট্য

✅ **১০০টি উন্নত বিশ্লেষণ লজিক**
- ট্রেন্ড বিশ্লেষণ (10টি লজিক)
- মোমেন্টাম বিশ্লেষণ (10টি লজিক)
- ভলিউম বিশ্লেষণ (10টি লজিক)
- মূল্য কর্ম (10টি লজিক)
- সাপোর্ট/রেজিস্ট্যান্স (10টি লজিক)
- প্যাটার্ন স্বীকৃতি (10টি লজিক)
- অসিলেটর ইন্ডিকেটর (10টি লজিক)
- মুভিং এভারেজ (10টি লজিক)
- বোলিঞ্জার ব্যান্ড (10টি লজিক)
- রিস্ক ম্যানেজমেন্ট (10টি লজিক)

✅ **ফ্লোটিং উইজেট**
- সব অ্যাপের উপরে কাজ করে
- স্ক্রিনে যেকোনো জায়গায় রাখা যায়
- দ্রুত স্ক্যান বাটন

✅ **রিয়েল মার্কেট বিশ্লেষণ**
- যেকোনো মার্কেটের চার্ট স্ক্যান করে
- 1 মিনিটের ট্রেড সিগন্যাল
- 90%+ একুরেসি

✅ **সিগন্যাল বিজ্ঞপ্তি**
- আপ সিগন্যাল (সবুজ)
- ডাউন সিগন্যাল (লাল)
- আত্মবিশ্বাস মাত্রা দেখায়

## ইনস্টলেশন

### পদ্ধতি ১: APK সরাসরি ডাউনলোড করুন

1. [Releases](https://github.com/mdsakibjibonsk-ops/Quotex-Signal-Trading-Bot/releases) পৃষ্ঠায় যান
2. সর্বশেষ সংস্করণ ডাউনলোড করুন
3. APK ফাইল আপনার ফোনে ট্রান্সফার করুন
4. ফাইল ম্যানেজারে খুলে ইনস্টল করুন
5. অনুমতি দিন এবং সম্পন্ন করুন

### পদ্ধতি ২: ADB দিয়ে ইনস্টল করুন

```bash
adb install app-release.apk
```

### পদ্ধতি ৩: নিজে বিল্ড করুন

```bash
# প্রয়োজনীয়তা:
# - Android Studio
# - JDK 11+
# - Gradle

./gradlew clean
./gradlew assembleRelease
```

## ব্যবহার

1. অ্যাপ খুলুন
2. "ফ্লোটিং উইজেট চালু করুন" এ ক্লিক করুন
3. অনুমতি প্রদান করুন (যদি প্রয়োজন হয়)
4. Quotex বা অন্য ট্রেডিং অ্যাপ খুলুন
5. চার্ট স্ক্যান করতে উইজেট আইকনে ট্যাপ করুন
6. সিগন্যাল প্রাপ্ত হবে
